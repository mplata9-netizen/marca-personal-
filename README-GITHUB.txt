PLATA STUDIO — SITIO WEB ESTÁTICO

ARCHIVOS
- index.html: página principal
- styles.css: estilos y diseño adaptable
- script.js: menú, animaciones y galería ampliable
- assets/: fotografías y logotipos usados por la página

IMPORTANTE PARA GITHUB PAGES
1. Descomprime este ZIP en tu computador.
2. Entra al repositorio de GitHub de tu sitio.
3. Sube TODO el contenido de esta carpeta a la raíz del repositorio.
   Debes ver index.html, styles.css, script.js y la carpeta assets al mismo nivel.
4. En Settings > Pages, elige Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), y guarda.
6. Espera a que GitHub Pages termine la publicación.

NO subas solamente index.html. Las imágenes dependen de los archivos dentro de assets.
NO cambies los nombres de los archivos ni las mayúsculas/minúsculas: GitHub distingue entre mayúsculas y minúsculas.
Las rutas de imágenes y archivos son relativas (assets/...), por lo que funcionan en GitHub Pages.

Para probarlo localmente, abre index.html con un navegador. Para una prueba más fiel, usa la extensión Live Server de VS Code.
